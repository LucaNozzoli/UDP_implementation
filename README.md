# UDP_implementation
UDP implementation for ICSR30

This project has the objective of emulating the UPD protocol using python following [this instructions](https://pessoal.dainf.ct.utfpr.edu.br/maurofonseca/doku.php?id=cursos:icsr30:trab2&authuser=3).


## Run instructions
The first step is to iniciate the server
```bash
python3 startup_server.py
```

Then start the client
```bash
python3 startup_client.py
```

From it you can choose the options to transfer the chosen files.
